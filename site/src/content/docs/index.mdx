Halison Code is a mod for Minecraft Java Edition. You get a small robot, Kintro, in your world, and you program it in
an editor in your web browser, in the style of Microsoft MakeCode. Each block you run makes the robot do one thing in
the game: walk, build, dig, find blocks, craft or fill a chest.

<CardGrid stagger>
  <Card title="Three ways to code" icon="puzzle">

  <Card title="A robot in your world" icon="rocket">
    Move, build, dig, find blocks, fill shapes, craft, smelt and sort chests. Several robots can work at once.
