Halison Code er en mod for Minecraft Java Edition. Du får en liten robot, Kintro, i verdenen din, og du programmerer
den i en editor i nettleseren, i samme stil som Microsoft MakeCode. Hver blokk du kjører, får roboten til å gjøre én
ting i spillet: gå, bygge, grave, finne blokker, lage ting eller fylle en kiste.

Halison Code er gratis og åpen kildekode (MIT). Det er en forhåndsversjon for testing. Det er ikke et offisielt
Minecraft-produkt, og er ikke godkjent av eller knyttet til Mojang eller Microsoft.
