Start Minecraft first

The editor runs inside the game. Start Minecraft with Halison Code and open a world. Then press H, or type /halisoncode in the chat, and the editor opens here.

Your projects are safe: they are kept in this browser.

Start Minecraft først

Editoren kjører inne i spillet. Start Minecraft med Halison Code og åpne en verden. Trykk så H, eller skriv /halisoncode i chatten, så åpnes editoren her.

Prosjektene dine er trygge: de ligger i denne nettleseren.
